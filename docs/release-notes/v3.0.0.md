# v3.0.0 — 瘦身与解耦

这一版**换了内部骨架**：把「工具自身」与「被治理的项目」彻底分开，砍掉一半以上的规则文本，
并修掉三处会静默给错答案的缺陷。

用起来有三点不同：**读得更少、判得更准、留下的东西看得见**。

## 改了什么

### 判断依据从「几十个开关」变成「项目自己的一节」

旧版有 12 个 `--no-*` 开关要记，还有一个藏在目标项目里的 `.project-forge/ledger.json`
账本。现在两者都没有了。

只有使用者能定的事（要不要许可证、要不要 CI、收不收外部贡献）写进目标项目
`AGENTS.md` 的「## 取舍」节。**决定成了项目的一部分**：能读、能争论、能跟着项目一起交接。

同时把结论分成三档，只有「不说会出事」的那一档才拦：

| 档 | 例子 | 拦不拦 |
| --- | --- | --- |
| 缺 | 凭据进了历史、工作流把密钥交给陌生人、没有 README | 拦 |
| 待定 | 要不要放许可证——只有你能定 | 问一次 |
| 可以更好 | 单语 README、个人项目没配 CI | **不拦** |

### 痕迹看得见，交棒能真交

旧版的痕迹判定靠一份哈希账本倒推「这段是不是我写的」。账本藏得深、用户不知道它存在，
丢了还会让工具退化成「什么都不认」。

现在每一处痕迹都带 `project-forge:` 标记，**就写在文件里**：能 grep、能手工删，
也能一条命令清干净。`handoff.mjs --scan` 只报告不动手，`--verify` 判断干净与否。

### 引用一次能读完

一次全量任务的必读量从 3,237 行降到 832 行。`references/` 从 16 篇 6,151 行合并成
8 篇 1,273 行；按能力面合并，不再为每个生态单开一篇。

### 勘察快了三十倍

旧版在一个 300 文件的仓库上要 27 秒，现在中位数 0.7 秒。原因不复杂：把逐文件问
「这个文件被忽略了吗」改成一次批量查询，并把八次版本控制查询改成并发。

## 修了什么

三处会**静默给出错误建议**的缺陷，现在都修好了，而且各有断言看着：

1. **没有 CI 时给错的开关**：旧版提示「加 `--no-ci`」，实际给的是 `--no-auto-release`。
   原因是结论先被拼成一句话，再回头去 `includes` 那句话里的词——文案一改，路由就失配。
2. **缺 PR 模板时给错的开关**：同上，给的是 `--pr-template-kept`。
3. **指错参考章节**：许可协议那一节指向「第四节」，而它实际在第六节。

治法是**把结论从字符串改成记录**：`{id, level, title, ref}`。渲染与「下一步」读同一个
对象，物理上不可能漂移；`ref` 指向的节标题由自检机器核对它真的存在。

另外修掉的：`--remember` 写进账本的决策键与读取时的键形状不一致，导致**存得进、读不回**。

## 需要你做什么

**旧版处理过的项目建议跑一次清理**。旧版会把 `scripts/review-record.mjs`（1,027 行）和
`.project-forge/` 目录拷进目标项目，这一版不再产生它们：

```sh
node "<本 skill 目录>/scripts/handoff.mjs" "<项目目录>" --scan
```

它会列出旧版残留，**确认之后自己删**——脚本不会替你动。

其它变化：

- **Node 18 起**（旧版写 16，但有两个脚本其实要 18）。
- `SKILL.md` 的 `P0–P8` 与 `G1–G11` 两套编号合并成 `S1–S4` 四步。
- `references/` 从 16 篇减到 8 篇，旧的文件名已不存在。如果你在别处引用过它们，
  按能力面对应到新的那一篇。
- `compose-agents.mjs --record`、`--status` 的记账分支、`review.mjs --remember` / `--forget`
  全部移除。

## 怎么升级

解压覆盖到你所用宿主的用户级 skill 根，目录名保持 `project-forge`。

```sh
# 确认这一版能用
node "<本 skill 目录>/scripts/dev/preflight.mjs"
```

## 已知问题

- 手上这份副本如果是从更早的版本一路覆盖上来的，`docs/` 与 `.github/` 里可能还留着
  旧文件。它们只服务本仓库，不影响使用；想清干净可以按 `git status` 逐个删。
- 旧版留下的目标项目痕迹识别得到，但**不会自动删**——这是设计：删除不可逆，
  得你说一声。

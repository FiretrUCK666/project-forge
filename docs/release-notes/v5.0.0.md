# v5.0.0

project-forge 从一次性仓库初始治理扩展为内置 5 套日常研发技能，覆盖探索、规划、分支流转、独立审查与技术债巡检，同时支持空白目录起步与存量项目写前快照保护。

## 重点变化

- **内置 5 套零依赖研发技能与无损装配**：目标项目的 `.agents/skills/` 内置 `dev-explore`、`dev-plan`、`dev-flow`、`dev-review` 与 `dev-govern`，覆盖只读结构梳理、方案拆解、隔离流转、独立审查与技术债巡检；`scripts/equip.mjs` 基于 SHA256 三态清单自动更新未改动技能，原样保留目标仓的手工定制与自有扩展技能，并清理退役旧文件。
- **空白目录起步与存量写前快照**：`equip.mjs --bootstrap-empty` 支持 `node`、`python`、`go`、`rust` 与 `docs` 等五种项目类型从零文件生成基础工程骨架、冒烟验证与初始 `docs/TDD.md`；修改任何非空存量仓库之前，先由 `scripts/backup.mjs` 在仓库外部生成增量 `.tar.gz` 快照并输出 10 项不覆盖处置计划，已有手写文档与目录保持不变。
- **双轴五态身份识别与四级 GitHub 通道**：联合远端拓扑与写权限证据识别 `local-only`、`maintainer`、`contributor-fork`、`clone-readonly` 与 `undetermined`，并区分个人仓库所有者与同源团队协作者 `team-collaborator`；支持在 `gh` 命令、环境变量令牌、代理服务与纯离线环境之间自动降级，权限不足的标签设置自动跳过。
- **四层文档体系与联动同步核对**：确立常青设计文档 `docs/TDD.md` 与 `docs/prd/`、`docs/specs/`、`docs/todo/` 四层协作文档结构，统一采用 YAML Frontmatter 并在关联 Issue 后自动重命名为 `YYMMDD-issue<N>-<slug>-{prd,spec,todo}.md`，同时兼容读取既有的项目符号头格式文档；`AGENTS.md` 控制在 30 KB 预算内，配齐写前防覆盖保护与「改哪看哪」联动同步核对，修改单侧文件时自动提醒检查邻近规则与模板。
- **实证门禁、安全隔离与技术债巡检**：确立形式校验、真实运行测试与界面渲染实证优先于静态挑刺的审查原则，针对界面或矢量图变更自动要求实际渲染与浅深色对照核验；补齐外部贡献提案的供应链投毒静态扫描、并行 Worktree 共享依赖的防删穿安全卸载，以及测试分层控频治理、文件膨胀与低效测试巡检和 `release-prep` 发版筹备命令。
- **浅深色可读的双语 README 与图解**：重写双语 `README.md` 与 `README.en.md`，并配齐 6 张 `assets/readme/*.svg` 工程流程与技能图解，在浅色与深色页面模式下均保持清晰对比度与无障碍可读性。

## 修复问题

- 修复克隆他人公开仓库时误判为 `maintainer` 进而尝试直接推送的问题：现在核对仓库归属与本地写权限证据，缺少写权限时默认拦截直推并引导选择后续协作路径。
- 修复纯 SSH 密钥环境下探测身份误报缺少凭据或弹出交互密码窗的问题：探测过程全程禁用终端交互提示，识别协议错配并给出具体切换命令。
- 修复跨月重入已有仓库时 `AGENTS.md` 与 `docs/TDD.md` 失效源码路径未检出的问题：重新运行勘察会自动核对声明路径、命令脚本与新增顶层模块，并提示定向校准。

## 不兼容变更与迁移

- 最低运行环境保持 Node.js 18 及以上版本不变，全部脚本继续保持零第三方依赖。
- 任务文档目录由原先单一的 `docs/work/` 升级为 `docs/prd/`、`docs/specs/`、`docs/todo/` 与已合并归档目录 `docs/archive/todo/`；既有项目中的历史工作记录可以继续保留或按需迁入归档目录，原有构建与检查命令不受影响。

## 升级方式

下载并覆盖更新到用户级 `project-forge` 技能目录后，可以先运行一次只读核对确认副本状态：

```sh
node "<本 skill 目录>/scripts/update.mjs" --check
```

已经完成治理的目标仓库如需同步新版 5 套研发技能与 `AGENTS.md` 受管区间，可以在目标仓库根目录先创建写前快照，再按需重新运行装配与合成命令，既有手写规范与自定义技能会原样保留：

```sh
node "<本 skill 目录>/scripts/backup.mjs" create . --label pre-upgrade
node "<本 skill 目录>/scripts/equip.mjs" .
node "<本 skill 目录>/scripts/compose-agents.mjs" .
```

# v6.0.0

project-forge 升级为支持两档按需装配、非 GitHub 远端自适应与纯本地运行模式的通用工程治理套件，并补充从需求勘察、多轮澄清规划、Worktree 隔离实现到双门独立审查与复盘收敛的完整日常研发流程。

## 重点变化

- **两档渐进装配与无损定制保留**：新增 `lightweight`（精简契约 `< 14KB` + 探索/规划/流转 3 个日常技能）与 `full`（完整契约 `<= 30KB` + 全部 5 个技能与协作骨架）两档配置，随时可运行 `--tier full` 升档；通过 SHA256 清单记录停用项与定制文件，支持接管本地手写改动与保留已有规范，重入升级不再误覆盖。
- **跨平台纯 JS `.zip` 写前快照与原子自更新**：修改任何非空存量仓库前的外部备份默认切换为纯 JS `.zip` 增量快照，不依赖外部打包命令并兼容恢复历史 `.tar.gz` 备份；压缩包副本的自更新改为同盘暂存校验、先更新辅助文件再原子替换清单文件，中断或检验异常时整目录原地回滚。
- **14 种技术栈空白起步与真实命令探测**：在精准识别 12 种语言生态之外，面对任意其他语言改为从项目现有的 CI `run:` 步骤、`Makefile`、`justfile` 与 `Taskfile` 读取真实执行命令；空目录起步新增支持 `12` 种语言加通用（`universal`）与纯文档（`docs`）共 `14` 种工程基线预设（不生成玩具示例代码），并与已有 `README.md` 和 `LICENSE` 共存。
- **全 Worktree 隔离流转与双门独立审查**：有提交历史的仓库默认分配隔离 Worktree 槽位开发，跨轮返工复用同一槽位并安全解绑重挂载共享依赖，合并前先在临时试合位跑通验证再推进主干；统一由单入口状态路由判断下一合法操作，按变更范围自动分级要求静态检查、实证测试与独立上下文审查，支持外源 PR 供应链安全扫描、连续退回停损、增量范围限制，以及中文结论大标题的结构化 PR/Issue 审查同步、外部依赖图谱与并行批次调度。
- **非 GitHub 远端与纯本地仓库自适应**：新增托管平台抽象，未匹配 GitHub 的远端自动按 `generic-git` 模式协作（合并后安全收尾，不在本地越权强合主干），无远端仓库也可完整跑通本地分支开发、审查与试合流程；远端与凭据探测全面禁用终端交互弹窗，默认离线零等待，按需传 `--probe-auth` 再做在线验证。
- **多语言静态治理与复盘沉淀**：补充源码级空断言测试、纯 Mock 自证与 CI 降级静态扫描，以及文档死链与架构图文本宽度校验；日常验证、返工与审查记账时自动记录处置信号，支持通过复盘命令提取面向下一轮规划的规则补丁。
- **双语门面、直连下载与发版附件校验**：重写双语 README 并重绘 6 张在浅深色下均可读的自包含矢量图解，安装表直接提供点击下载链接；发布流水线新增包目录白名单核对与上传后下载回读 SHA256/CRC32 校验，并在常规自检中加入常青文档防过时检查。

## 修复问题

- **修复跨平台并发执行偶发挂死与离线探测阻塞问题**：子进程调用统一禁用开放标准输入管道并加设超时保护，修复 macOS Node 18 下并发排水挂死以及无网络环境探测凭据卡死的问题。
- **修复多人协同身份、归档计数与合入拦截误判**：修复团队协作者与人工合并授权规则的误判、提交 PR 后漏填归档编号导致工作区变脏、未等远端 CI 全绿即试图合并，以及不同系统路径大小写与跨时区下的状态比对偏差。
- **修复浅克隆遗漏、归档死链误报与文档断链**：修复发版筹备仅扫描浅克隆历史导致变更遗漏的问题、文档死链检查误报历史归档目录的问题，以及部分文档相对路径指针失效的问题。

## 不兼容变更与迁移

- **最低运行环境保持不变**：仍要求 `Node.js 18`（`>= 18`）及以上版本，全部脚本保持零第三方依赖。
- **已有治理仓库同步建议**：此前已装配过旧版的项目，按下方升级命令创建写前快照并重新装配工具套件与契约后即可启用新工作流与两档机制，既有手写规范与自定义技能会原样保留，原构建与测试命令不受影响。

## 升级方式

如果本机通过压缩包方式安装 `project-forge`，覆盖更新后（或运行检查命令）确认副本版本与完整性：

```sh
node "<本 skill 目录>/scripts/update.mjs" --check
```

如果需要将已经治理过的目标仓库同步升级到最新 5 套日常技能与 `AGENTS.md` 受管区间，请在目标仓库根目录先创建写前快照，再运行装配与合成命令：

```sh
node "<本 skill 目录>/scripts/backup.mjs" create . --label pre-upgrade
node "<本 skill 目录>/scripts/equip.mjs" .
node "<本 skill 目录>/scripts/compose-agents.mjs" .
```

# v7.0.0

project-forge 升级为覆盖需求探索、规划、改码门禁、流转、独立审查、验证工具沉淀、治理审计与盲区补测的 8 技能全周期研发治理体系，并引入多主题对话状态机、v3 无损升级账本与规范化 CLI 契约。

## 重点变化

- **8 套日常研发技能闭环与 v3 无损升级账本**：在原有 5 个核心技能基础上新增 `dev-edit`（改前禁改区/复用核对与词法去噪静态门禁）、`dev-verify-tools`（验证工具生命周期与唯一机读功能地图）与 `dev-iterate`（盲区识别、定向补测与并发压测升级），贯通八阶段日常研发闭环；升级到 v3 账本并支持四类存量资产融合、墓碑记忆、定制文件豁免与零污染三方合并，旧仓重入升级不覆盖手写规范。
- **多主题对话记忆与全周期 `OPEN`/`LOCKED` 两态状态机**：支持在同一对话中记录并切换多主题探讨，经跨主题简报与未决问题门禁防丢上下文，并在进入执行前收敛为锁定状态；支持按需锚点、授权删减、`dropped` 终态、1:N 总控需求分阶段切片推进，以及面向已完成或锁定规划的受控 `--reopen` 重开流转。
- **CLI 规范参数归一化与结构化指引**：统一各技能脚本的 `--agent`、`--mode`、`--host-mode` 等公共参数与退出码语义，保留旧参数的静默向后兼容别名；标准命令在 `--json` 输出下均附带可机读的 `nextSteps` 下一步路由。
- **Skill 双线体积门禁与双语门面重构**：为全部内置技能落盘 `14KB` 预警与 `16KB` 硬拦截双线预算门禁，完成全套内置技能去膨胀（全部 `< 14KB`）；同步精简重构中英文 README 排版，并配备在浅色与深色主题下均可清晰阅读的自适应矢量图解。
- **确定性工单质量契约与 1:N 联动闭环**：开工阶段严格校验并复用已有工单或按统一质量模板自动建单回链，支持主干规划与多切片子任务在开单、PR 模板填充、标签流转与合并收尾时的联动同步。
- **常青文档、功能地图与验证工具保鲜闭环**：提供零写入按需切片定位、架构基线与代码漂移巡检、发版筹备变更聚合及验证工具树哈希保鲜校验，防止工程文档与验证资产随迭代失真。

## 修复问题

- **修复 1:N 规划摘要与路径对齐问题**：修复多切片规划下的总控摘要进度同步、跨路径审计根目录判定与归档文档相对路径解析偏差。
- **修复 PR、标签与升级工单联动问题**：修复提交 PR 后模板字段与里程碑继承遗漏、工单自动关闭与残留状态标签未清理的问题，以及工具包重入升级时上游更新与本地定制的区分偏差。
- **修复验证工具缓存继承与体积限制问题**：修复隔离工作树下验证工具基线缓存未正确继承、缓存清理与超大文件校验阈值误判问题。
- **修复跨平台并发稳定性问题**：修复多平台环境下并发子进程调用、测试生命周期隔离与非交互 Git 探测在边界条件下的稳定性问题。

## 不兼容变更与迁移

- **最低运行环境保持不变**：仍要求 `Node.js 18`（`>= 18`）及以上版本，全部脚本保持零第三方依赖。
- **CLI 与对话状态无缝迁移**：所有既有 CLI 参数旧写法均保留静默向后兼容别名，原有工作流调用无需立即改动；已有 `session-state` 对话状态数据自动无损迁移至 v2 结构。
- **已治理仓库推荐升级动作**：此前已装配过旧版的项目，按下方升级命令创建写前快照并重新装配 8 套技能与受管 `AGENTS.md` 契约区间后，即可启用新增的 `dev-edit`、`dev-verify-tools`、`dev-iterate` 与最新门禁，既有手写规范与自定义技能会原样保留。

## 升级方式

如果本机通过压缩包方式安装 `project-forge`，覆盖更新后（或运行检查命令）确认副本版本与完整性：

```sh
node "<本 skill 目录>/scripts/update.mjs" --check
```

如果需要将已经治理过的目标仓库同步升级到最新 8 套日常技能与 `AGENTS.md` 受管区间，请在目标仓库根目录先创建写前快照，再运行装配与合成命令：

```sh
node "<本 skill 目录>/scripts/backup.mjs" create . --label pre-upgrade
node "<本 skill 目录>/scripts/equip.mjs" .
node "<本 skill 目录>/scripts/compose-agents.mjs" .
```
